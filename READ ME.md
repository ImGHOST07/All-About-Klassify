# Klassify Website

Static website for **Klassify**, a mobile app that helps schools and colleges take, track and report student attendance.

## Pages

- `index.html`: homepage describing what the app does
- `privacy.html`: Privacy Policy
- `terms.html`: Terms of Service

## Hosting

Plain HTML and CSS with no build step. Served with GitHub Pages on a custom domain.
